# 基础材质库与自定义符号

2026-09-11。采用一套基础规则，由用户提供的图框图例建立；不按设计公司或现场拆分。本次是符号表示的实现，不推断材料选用条件。

## 启动与输入

双击项目根目录的“启动部材表生成器.cmd”，在主界面“图纸设置”中勾选“按材质库生成符号”。右侧“材质符号库”按钮可查看所有基础和自定义规则。所有功能使用同一个软件、Python 环境和设置保存位置；开关可随现场模板保存，重启后恢复上次选择。没有填写独立材质栏的旧 Excel 可先关闭此开关。

此前的“启动材质符号试验版.cmd”保留为兼容快捷入口，打开的仍是同一个软件，只是初始勾选材质功能。旧试验设置文件保留，未覆盖或删除；新界面使用原主程序的设置。

Excel 使用现有表头，在“材质／材質／材料”列填写完整材质，例如 `TMCP325B` 或 `TMCP 325 B`；“断面”列只填写 `H-900X300X16X28` 这样的尺寸。软件使用材质规则，将符号块放在断面文字前；输出表不再重复显示单独材质列。Excel 原文不被改成括号记号。

基础库包含 SS400、STK400、SM490A、STKR490、BCR295、SN400B、SN490B/C、TMCP325B/C、TMCP385B/C、BCP325B/C、BCP385B/C，共 16 个材质名称。`SS400` 与 `STK400` 明确配置为无记号；空白材质不是无记号。请先查看生成的“材质符号对照样张”。

旧测试 Excel 的材质栏为空，启用材质功能时程序会列出需要补充的 Sheet 和行号，不从断面记号猜完整牌号。断面不再按类型名单校验，槽钢 `[-100X50X5X7.5` 及其他写法均按原文输出，不提示未知类型、不替换字符、不自动删除已有前缀。无论是否开启材质功能，断面列均保留原始字符。材质功能仍会在断面前添加选定材质符号，原文若已有材质记号，应由用户决定是否在 Excel 中去除。字体缺字、单行绘制不支持的换行、内容超出可用区域仍会报错，避免输出不完整。BH 的腹板与翼缘采用不同材质时，尚未实现其特殊表达，不能将混合材质填成一个普通材质。

## 追加自定义符号

提供“材质全称＋正确记号截图或 CAD 图例”即可，由开发侧制作并追加。无需用户制作块。主界面的“材质符号库”目前用于查看规则，列表显示“材质全称”和“材质符号”两列。符号由出图使用的同一 CAD 块生成预览，直接展示字母与外框组合；无记号的材质显示“无”，不再分列描述前置文字、外框和框内文字。

`base.json` 保存基础规则；`custom.json` 保存新增材质，目前为空。规则在每次出图开始时重新加载一次，因此修改后下次出图即可生效。没有复杂的素材管理窗口。

以下为配置格式示例，EXAMPLE 只是示意名称，不是已启用材质：

```json
{
  "schema_version": 1,
  "symbols": [
    {"material": "EXAMPLE", "aliases": [], "prefix": "T", "inner": "B", "shape": "triangle"}
  ]
}
```

形状支持 circle（圆）、square（方框）、triangle（三角）、diamond（菱形）、pentagon（五边形）、hexagon（六边形）、star（星形）、none（无记号）。字母当前支持短英文字母。`none` 必须同时留空 prefix 和 inner。新增名称或别名不能覆盖已有规则；如需修订基础规则，应明确修改并重新确认样张。

特殊任意 CAD 块的导入、混合材质 BH、图例自动识别暂不属于本次功能。多边形需要更大的包围范围，放不下时会提示调整整表行高，不压扁符号。

## 输出与核验

CAD 使用 TEXT 字母与 LINE/CIRCLE 外框，组成可编辑的块。相同外观的材质共用块定义，每个单元格插入一个引用；符号定义随 DWG/DXF 一起保存，打开结果时不依赖外部素材文件。PDF 从同一 CAD 几何生成，文字可选中。

列宽计算包含完整符号、0.4 mm 的符号到断面间距以及原有左右各 0.6 mm 留白。行高、字号仍沿用当前固定排版，不能放入的符号会报错。

材质空白、未知材质、重复规则、不可显示字符和符号超出行高，会在材质检查时提示。新模式对整批图纸校验后再发布 DWG/DXF；输出报告记录每个 Excel 行号、原始材质、选用规则、块名、单元格范围和规则文件摘要。DWG 转换后核对块的位置、缩放、圆半径、框线端点与字母。

已有“部位”列在用户 CAD 中的显示问题仍待现场验证；材质功能的程序检查不等于该问题已解决。本次未进行多 Sheet 性能计时，也未声称达到免人工检查的正式交付水平。

## 回退与命令行

在主界面取消勾选材质功能，即可使用原表格方式。功能前的源码快照保存在 `backups/材质功能前_20260910`，没有覆盖原 Excel、图框或旧交付文件。

命令行启用：`main.py --material-symbols --input <Excel路径> --output <输出目录> --formats pdf,dxf,dwg`。也可在现场模板中设置 `"material_symbols": {"enabled": true}`。

刷新符号对照样张：`tools/preview_material_symbols.py --output <样张目录> --dwg`。DWG 依赖原有转换组件；软件交付形式为源码，DWG 文件仍正常支持。
