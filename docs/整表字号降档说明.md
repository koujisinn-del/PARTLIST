# 空间不足时的整表字号降档

主界面提供三种选择，默认保持字号：

| 选择 | 尝试顺序 |
| --- | --- |
| 保持字号 | 只使用原字号及同页续表 |
| 最多降一档 | 原字号放不下时，尝试原字号的 90% |
| 最多降两档 | 依次尝试原字号、90%、80%，使用第一个能放下的档位 |

每一档都相对原始字号计算，两档为原字号的 80%。行高也同比调整，例如默认纸面字高 1 mm、行高 2.5 mm，分别变为 0.9 / 2.25 mm 或 0.8 / 2 mm。

只有用户明确选了允许降档，而且原字号排版确实无法容纳时，才会降档。原字号能够通过同页续表放下时，继续使用原字号。每张图内所有类别、标题、表头、正文和材质符号统一使用同一档；不单独缩小某个单元格，不修改原始断面字符或部件名称。

实际降档后，完成提示会列出哪些图纸调整到了 90% 或 80%，生成报告还记录实际档位、纸面字号和行高。材质符号继续与断面同字高、同基线；CAD 输出倍率再作用于已经排好的纸面图形，PDF 仍是 A3。

即使允许两档仍放不下，或缩小后低于程序设定的字号和留白下限，程序会明确停止，不继续缩小或跨页。未知材质、缺字、错误模板等问题仍按原错误处理，不用降档掩盖。

该选择会随用户设置和现场模板保存。旧模板没有设置时保持字号。命令行可用 `--auto-text-shrink-steps 0`、`1` 或 `2`；未指定时沿用现场模板。

请按现场打印清晰度决定是否允许降档；CAD 字体和实际打印效果仍需在 AutoCAD LT 2024 验收。
