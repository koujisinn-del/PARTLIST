部材表图纸生成器（中文版）

1. 本软件是便携版。把整个文件夹复制到另一台 Windows 电脑后，双击“部材表图纸生成器_中文版.exe”即可；不需要安装 Python，也不需要管理员权限。
2. 依次选择 Excel、输出文件夹，以及可选的本地 DWG/DXF 图框。
3. 最上方“现场模板”可直接输入名称，也可从下拉框选择已有名称。选择后不会自动改变设置，必须点击“读取”才会套用。
4. 输入名称并点击“保存”，会把当前输出文件夹、图框路径、排序、输出格式和内部表格设置保存为模板；同名时会询问是否覆盖更新。只记录 DWG 路径，不会把 DWG 文件塞进模板。软件会记住最后一次读取或保存的模板。
5. 建议先点“读取并预览 Excel”，确认 Sheet 和内容，再点“生成图纸”。
6. Excel 预览是只读的。图纸列表标红会按现场模板中的“本次提出日期单元格”规则直接保存到原 Excel。
7. 配置和日志保存在当前 Windows 用户的 LocalAppData\MaterialDrawingGenerator 中。
8. 如果 Excel 正被 Excel 软件锁定，请先保存并关闭该文件再生成。
9. 如 Windows 首次运行提示“未知发布者”，这是因为当前开发包没有购买代码签名证书；请核对文件来源后再运行。

当前仍待现场样例确认：正式表格坐标、指定字体/图层、图纸列表的本次提出日期单元格、楼层绑定注记 DWG。
