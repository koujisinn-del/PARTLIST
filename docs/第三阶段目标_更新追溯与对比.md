# 第三阶段目标：轻量更新追溯与二次核对

记录日期：2026-09-13。状态：需求整理，尚未开发。

## 启动条件与分支安排

- 当前继续验收材质符号功能。用户确认其无问题后，才启动第三阶段。
- 保留经用户确认的稳定源码与配置基线，在独立开发分支开展第三阶段，不直接改动稳定版。当前目录尚不是 Git 仓库，本次没有创建 Git 分支；正式开始时再建立版本管理及开发分支，具体名称届时确认。
- 未通过新阶段验收前，不替换稳定交付包。试验数据和配置应隔离，避免试验版本覆盖稳定版首选设置、自定义符号或正式履历。

## 核心目标

Excel 是内容及人工更新标记的来源。生成器忠实输出，比较功能作为二次核对，用来发现漏标、共同作业中未周知的改动，以及被删除的记录。不建立复杂的审批或协作平台。

## 颜色规则

| 对象 | 第三阶段目标规则 |
| --- | --- |
| Excel 部件表文字 | 继承 Excel 的字体颜色；红字保持红色，不由差异比较擅自改红或改黑 |
| 图框中的注记 | 可以为红色；按明确的注记范围保留源颜色 |
| 图框其他固定内容 | 不因为比较发现变化而自动变红；正常黑白输出 |
| 图纸日期履历、版本号等自动填入字段 | 随数据更新，但不因更新而变红，正常黑色输出 |
| 已删除记录 | 不在新图纸留占位或额外标记；在软件变更清单中保留被删除内容 |

不新增修订云线、三角标记等图面标注。以上是目标，不代表当前程序已经支持颜色继承。注记与其他图框内容的识别方式待确认，优先采用明确的图层、块或区域，不依据颜色自行猜测。

## 功能范围

### 轻量快照及保留管理

- 优先保存结构化数据，不为每次生成重复复制整份 Excel、DWG、PDF 或截图。JSON 等格式可作为候选，最终格式待实现前确定。
- Excel 每次任务只读取一次；出图、快照、比较复用同一份解析结果。不为了决定是否保存快照而额外读取原文件或解析 CAD。
- 成功生成后的记录关联实际生成所用数据；失败任务不冒充成功出图记录。
- 相同数据可共用一个数据快照，不同生成事件或提出记录只引用它。配置也可按内容摘要复用，避免冗余。
- 普通历史限制数量；手动保留、已提出记录和当前比较基准受保护。数量、容量和清理时机待定，不能清理仍被保护记录引用的数据。
- 不强加一套用户需要维护的内部版本号。内部记录标识只用于追溯，允许同一对外图纸版本号对应多次修正或发送记录。

### 二次对比

- 可选历史记录作为比较基准，列出新增、修改、删除；修改展示字段名称及修改前、修改后值，删除保留原记录。
- 内容改变但未标红：提醒检查，不自动修改 Excel 或图纸颜色。
- 已标红但相对基准无变化：可作为参考提示，不认定错误、不自动去红。
- 内容变化与仅颜色变化分开记录；图纸日期和版本等元数据单独展示，不混入部件修改标红提示。
- 不按行号匹配；部件名严格区分大小写。重复同名同部位、部件改名、拆分或合并等对应不明确时应显式提示，不默默猜测。
- 核对界面、修改清单和日志共用一份差异结果，避免各算一套导致遗漏或不一致。

### 备注及追溯依据

- 支持整次生成／修正记录的备注，也支持单项变化的备注；非强制填写。
- 支持多个参考链接及可读标题，可粘贴 OneDrive 文件、Teams 消息或会议等链接，作为修改依据。
- 先只存储和打开用户提供的链接，不接入云端同步、不自动读取消息、不自动上传文件。访问仍取决于公司账号和原链接权限；链接不等同永久归档。
- 备注和链接可以后补或修订，但不能改写已保存的原始数据快照。连续修订中备注如何继承、重复改动如何对应，需明确规则后实施。

### 同版本号继续修订

- 已提出的 D 保留原状，不覆盖、不假装未发出。之后可生成同一对外版本号下的 E、F。
- 可与 D 比较本次追加修改，也可与更早的 A 比较整个版本累计变化。切换基准不改变 Excel 红字或输出颜色。
- “保留记录”“标记已提出”“设为比较基准”是独立状态。误选基准可以调整；提出状态修正应留下操作记录，不删除曾发送过的文件事实。

## 界面与效率约束

- 主界面保持简洁，优先只增加核对入口及当前基准提示；历史、保留、备注、链接放在独立窗口。
- 支持直接生成和选择进行二次核对，不让每次排版试生成都经过繁琐流程。若勾选核对，未结束前不得显示“核对完成”。
- 差异比较处理结构化数据，不比较 CAD 图形或渲染图片。开发时测量新增开销，再与用户确定可接受范围；不预先承诺零耗时。

## 建议实施顺序与验收

1. 经确认的材质版本留档并建立独立开发分支。
2. 快照、引用去重、保留机制及手动选择基准。
3. 新增／修改／删除对比，尤其验证重复记录和仅排序变化。
4. Excel 红字、图框注记颜色继承，以及日期版本字段不自动标红。
5. 备注、多个参考链接及同版本号追加修订流程。
6. 完整回归、开销评估和现场使用验收后再决定交付。

重点验收：同样数据重复生成不膨胀存储；排序不误判修改；删除可追溯；改后恢复原值正确反映；同版本多次修订可分别及累计比较；基准调整不丢红字；保护记录不被清理；共同编辑未标红改动可提示；备注和链接不串到其他记录；Excel 原件不被比较功能擅改；PDF、DWG 的目标颜色一致。

暂缓事项：云端协作平台、自动抓取 OneDrive／Teams 内容、自动审批、复杂内部版本命名、全量 CAD 图形差异分析。程序核对不等于工程数据正确性审查，不能保证无需检查即可提交。
