# 出图效率优化方案（待实施）

日期：2026-09-04。依据现行源代码及同日实际计时整理。本次不修改生成逻辑，不调整排版，不打包。

后续状态：同日用户要求暂停耗时测试，优先修复 DWG 并落实已确认的排版需求。项目已改为真实文字 PDF 输出并合并图纸 list；下文保留为当时的分析记录，其余性能方案暂缓，不代表修复后的流程和耗时。详情见项目开发记录第十节。

## 1. 结论与依据

主要优化对象是 PDF 绘制流程，不是 Excel 读取。用户固定 Excel 格式、DWG 定位规则仍有价值，但更直接的收益是减少识别错误、提高定位稳定性。

| 12 张图纸，2,280 行 | 实测中位数 |
|---|---:|
| 仅 PDF | 79.3 秒 |
| 仅 DWG | 11.6 秒 |
| PDF＋DWG | 87.6 秒 |
| 仅 PDF 中的 Excel 读取 | 0.07 秒 |
| 仅 PDF 中的中间 CAD 绘制 | 4.41 秒 |
| 仅 PDF 中的 PDF 渲染 | 74.76 秒 |

PDF 渲染占仅 PDF 总耗时约 94%。即使完全省去 Excel 读取，也只省约 0.07 秒。各阶段分别取中位数，加总不要求严格等于总中位数。

这是本机、缓存预热后、现行代码的文件生成时间，不含实体打印机出纸；未包含尚未实现的图纸 list 打印及多页 PDF 合并。详见 [计时记录](C:/Users/62301/Desktop/部材リスト/docs/生成耗时测试_2026-09-04.md)。尚未对优化方案测速，不能承诺具体倍数或秒数。

## 2. 目前流程中可简化的工作

使用现场 DWG 图框时，目前每张图纸依次执行：

1. 读取转换后的图框，识别 A3 外框、归一化坐标、调整字体及定位文字。
2. 创建表格和文字，写出中间 DXF。
3. 生成 PDF 时，再读取 DXF，通过 CAD 绘制器重新绘制整张图。
4. 需要 DWG 时，再读取 DXF，建立 R2000 兼容副本，启动转换器输出 DWG。

已核实的细节：

- 原图框的 DWG → DXF 转换已经有磁盘缓存，不是每张都重新转换原 DWG；新增 PDF 图框缓存是另一层优化。
- PDF＋DWG 已共用一次中间 CAD 绘制，不能再把“避免绘制两次”算作新收益。
- PDF 路径每页建立新的绘制对象；当前 CAD 绘制器将文字转成字形轮廓，再绘制轮廓和线条。这个流程确实存在，但尚未细分测出文字、线条、图框各占多少秒。
- 同一图框仍在每页重复解析、归一化和渲染；固定内容可以考虑预处理后复用。
- 单元格文字目前先估算，再测量实际包围框，必要时多次缩小。应随已记录的“同表同字号、长文字扩列”要求统一重构，不应仅为提速删除越框检查。
- 界面生成前为分类确认读取一次 Excel，正式生成又读一次；确有重复，但按现有数据规模不是主要瓶颈。
- DWG 的兼容清理是在解决实际 FIELD 等转换错误，不能简单删掉来换速度。

检查位置：`service.generate_drawings`、`gui._generate/_confirm_generation`、`drawing.CadAdapter/render_cad_pdf/convert_dxf_to_dwg`，以及当前安装的 CAD 绘制库文字与 PDF 输出路径。

## 3. 推荐优化顺序

| 顺序 | 方案 | 预期作用与限制 |
|---|---|---|
| 1 | 对 PDF 渲染做细分计时，并小范围比较更直接的 PDF 输出方式 | 先验证主要耗时究竟在文字轮廓、逐实体绘制还是写文件。候选方式必须保持 A3、字体、线宽及定位；新依赖须符合公司使用要求。 |
| 2 | 缓存固定图框，表格和变化文字直接绘入 PDF | 主攻约 75 秒的 PDF 阶段；不再为了 PDF 每页把完整 CAD 图转换为轮廓。改动中等，需要完整视觉回归。 |
| 3 | 一次生成共享排版结果，分别交给 PDF 和 DWG 输出 | 两种格式共用列宽、行高、字号、合并格、标题和履历位置；避免优化后两种图纸长得不一样。与已确认但待实施的新排版规则一起设计。 |
| 4 | 同一次任务复用图框预处理、字体与文字宽度测量，减少中间文件往返 | 对 PDF/DWG 均有帮助，但仅靠这些小优化难以消除目前主要等待。测量缓存需包含字体、字号和完整文字。 |
| 5 | 只重新生成变化的楼层 | 对日常局部更新很有价值；首次全量生成无收益。不能只看版本号，因为同版本也允许修改内容。 |
| 6 | 有限度并行生成独立楼层或转换 DWG | 最后再测试，例如同时处理 2～4 张。会增加内存和实现复杂度，不能假定开 4 个就快 4 倍；PDF 汇总仍按确定顺序完成。 |

现有代码已有用于内置图框的直接 PDF 绘制实现，可以作为基础，但不能直接切换就算完成：外部 DWG 固定图框、占位文字、字体度量和合并 PDF 都需要接好并核验。

### 推荐的 PDF 方向

首次保存或更新现场模板时，生成一次“固定图框 PDF 底板”，保留矢量线条与固定注记，不把图名、图号、版本、作成日、履历示例文字留在底板中；记录这些变化字段的位置和对齐方式。

日常出图只需读取 Excel、计算排版，在底板上绘制表格和变化文字，最后输出含图纸 list 的一个多页 PDF。DWG 则继续由同一份排版数据单独输出，保持可编辑。

图框缓存必须在 DWG、字体、黑白/线宽设置、纸张尺寸或模板处理规则改变时失效。楼层注记作为独立可复用内容处理，不把不同注记强行做成多个完整图框。

不要用截图作底板来换速度。动态文字优先使用可嵌入的中日文字体；必要的特殊记号使用小型矢量图形，保留放大及印刷质量。图框缓存本身只省固定部分，配合直接绘制动态表格才覆盖主要优化目标。

### 只更新变化楼层的安全边界

判断依据应包含该楼层全部有效数据、名称与编号、版本和日期履历、排序、排版配置、图框、注记和字体等，不仅比较 Excel 文件时间或版本号。某张数据或样式改变，才重建该张；公用图框改变则重建受影响的所有页。

即使复用未变楼层，也要正确更新图纸 list、执行应有的 Excel 标红保存，并重新组装完整 PDF。缓存不存在或校验失败时自动重建，不交付过期内容。

## 4. 用户准备文件时，可以做什么

### Excel：主要提高可靠性，不值得为速度大量返工

- 固定图纸 list 的 Sheet 名、表头行、图纸名列、图号列、版本日期列起点，以及本次提出日期单元格。
- 部材 Sheet 保留楼层名称；固定部件名称、种类、部位、断面、材质、接合、备注所在列，统一种类写法。
- 同名部件仍然一段断面一行，允许 1～N 行，不必预先合并名称；输出时由软件合并。
- 这些规则建议保存在现场模板中，而不是写死在所有现场共用的程序代码里。原有文件可保留自动识别方式作为兼容。
- 避免把不使用的几十万行、整列都铺上格式；但无需为了本次性能问题重做整个工作簿。

### DWG：一次做好定位，后续复用

- 新准备的模板可统一为纸面毫米坐标：A3 横向 420 × 297 mm、左下角为原点；现有其他比例模板可首次导入时转换确认后保存，无须手工重画。
- 明确固定图框区域、表格起点、横纵间距、可用宽高、履历起点与向上间距。固定表格排布规则，不固定实际种类数量。
- 将固定边框/公司信息/统一注记与图名、图号、版本、日期等变化内容区分图层或标记。每个变化字段唯一定位，不依靠相似文字猜位置。
- 后续可约定唯一属性标签，避免只用大小写不同的日期示例区分字段；新标签方案待实现，现版仍使用已有占位文字。
- 尽量只保留出图需要的内容；处理无用的远处辅助线、重复对象及外部依赖。不要为了“简化”把所有文字、图块全部炸开为碎线。
- 中日文使用约定且公司电脑可用的字体，特殊符号单独约定；避免不必要的大量字体混用。
- 可选：在 CAD 中额外导出一份同范围、同尺度、无额外留白的矢量 PDF 空白图框，供快速输出使用。变化字段应留空，位置由 DWG/模板记录。DWG 更新后 PDF 底板必须同步。若嫌维护两份麻烦，则由软件首次导入 DWG 时自动生成底板，更适合长期使用。

固定坐标主要省去定位猜测及部分预处理；单独定坐标并不能省掉目前整张 PDF 的重新渲染。

## 5. 不优先采用的方式

- 不把“Excel 列名全部写死”当作主要提速方案。
- 不用降低分辨率、输出整页图片、省略文字或跳过数据对账换速度；当前文字轮廓和矢量线条的处理不因简单降低 DPI 就消失。
- 不直接删除 DWG 兼容清理；可研究预清理固定图框并复用，但需验证新增对象与图层、字体关系。
- 不把多张 PDF 最后合并这一步本身当作主要提速点。要让页面共享底板及字体资源，并改变前面的绘制路径。
- 不立即增加复杂设置界面，也不打包 EXE。

## 6. 后续验收

先用原有 2 张和扩展 12 张基准比较旧、新输出，再记录首次使用模板与重复使用的时间、仅改一层的时间，以及 PDF、DWG、两者同时输出的时间。新格式的图纸 list 与 PDF 合并应另列增量耗时，避免与旧基准混为一谈。

同时检查：全部原数据对账、A3 尺寸和比例、黑白线宽、中文日文与特殊记号、同表字号行高、长文字扩列、合并格、图名/图号/版本/日期定位、完整履历顺序、汇总 PDF 页序及 DWG 实际打开情况。

长文字扩列后超过 A3 可用宽度的规则、最终单元格留白仍待确认，不能为了提速擅自单格缩字或拆成多页。

建议优先顺序：验证 PDF 新绘制路径 → 共享排版与固定图框复用 → 图纸 list 和单文件 PDF → 变化楼层复用 → 视实测再考虑并行和 DWG 深度优化。所有收益必须实际复测后再报告。
