# 图纸生成耗时测试记录

日期：2026-09-04（日本时间）。本次仅记录需求、构造测试副本并测量现行程序，不修改生成器功能，不打包 EXE。

## 输入和测试规模

- 使用 `テスト用部材データ0904.xlsx`、`図面テンプレート.dwg` 和当前默认现场布局配置。
- 原始组：2F、3F 两张楼层表，分别 164、216 行，共 380 行。
- 扩展组：保留 2F、3F，追加 4F～13F。偶数楼层复制 2F 内容，奇数楼层复制 3F 内容，共 12 张、2,280 行。
- 扩展工作簿保留合并表头，复制前后逐行核对部件名称、种类、部位、断面、接合、备注等全部读取字段；不更改复制行中的原部件名称。
- 仅在测试副本中重建与这 12 张表对应的图纸 list；日期沿用复制源的履历，新增图号使用 `TEST-04`～`TEST-13`。这些是性能测试数据，不是实际新增楼层的设计资料。
- 源 Excel、旧 DWG 和文字标记 DWG 均通过测试前后 SHA-256 一致性检查，原文件未修改。

## 测量口径

- 环境：当前 Windows 11 电脑，Python 3.12.10，20 个逻辑处理器。
- 各组实跑 3 次，共 18 次；顺序轮换、串行执行，避免并行测试争抢资源。
- 每次由独立 Python 进程调用现有 `generate_drawings`。不启动完整界面；从进入生成函数到它返回计时。
- 包含 Excel 读取与校验、图形绘制、实际 PDF 渲染/DWG 转换、写出文件和生成报告。
- 图框及字体磁盘缓存预热后开始计时。预热另做了一次两张表的 PDF＋DWG，耗时 12.670 秒，不计入下面的统计。未清理系统文件缓存，因此不是操作系统层面的冷启动测试。
- 不包含程序启动、界面操作、Excel 预览、测试工作簿的复制、测试后的文件检查，以及实体打印机的出纸时间。
- 当前 PDF 仍按楼层分别输出。尚未实现的图纸 list 打印、PDF 合并、自动扩列和同表强制统一字号规则不在此次计时范围内。

## 耗时主要在哪里

单独 PDF 模式的分段中位数：

| 阶段 | 2 张 | 12 张 |
|---|---:|---:|
| Excel 读取 | 0.016 秒 | 0.070 秒 |
| 绘制中间 CAD 数据 | 0.919 秒 | 4.414 秒 |
| PDF 渲染 | 9.882 秒 | 74.760 秒 |

各阶段分别取中位数，因此不要求加总严格等于总耗时的中位数。此次 PDF 渲染约占 PDF 模式总时间的 91%～94%，Excel 读取占比很小。两种格式同时输出会共用中间 CAD 绘制结果，无须把这部分做两次。

- 18 次测量全部完成，输出行数逐张与输入对账。
