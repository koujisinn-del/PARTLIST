# 100 / 150 / 200 倍率验收样张

使用虚构的 100 行材质部件和自建 150 倍源图框，通过真实 Excel 读取、同页续表、材质校验及 DWG 转换流程生成。图中 QA ONLY 数据不是工程成果。

- `scale_100.dxf` / `.dwg`、`scale_150.dxf` / `.dwg`、`scale_200.dxf` / `.dwg`：同一份内容的三个模型空间倍率。
- `a3_reference.pdf`：共同的 A3 横向纸面结果；切换 CAD 倍率后 PDF 排版不变。
- `pdf_comparison.json`：三份原始 PDF 的渲染像素及 Unicode 文字摘要；三档分别比较，相同即证明此次样张的 PDF 显示和文字内容未变。

原图框的满幅 A3 外框在三档 CAD 中分别为 42000×29700、63000×44550、84000×59400 mm；表格字高分别为 100、150、200 mm，符号和断面基线保持对齐。源图框、输入 Excel、base/custom 材质库的摘要前后相同。

请在 AutoCAD LT 2024 中分别打开三个 DWG，检查默认视图、文字可编辑、符号显示、续表及模型空间尺寸。本机回读不替代现场打开验收。日常使用默认选 150，需要时在“CAD 输出倍率”切换。

复现工具：`tools/generate_cad_scale_examples.py`，输出到 `output/pdf/cad_scale_20261027/`。使用当前程序时，安装和组件要求与主程序相同，不会下载依赖。
