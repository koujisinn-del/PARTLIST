# 生成前的输入检查

## 防止多图互相覆盖

工作表名需要整理为 Windows 可用文件名。不同名字可能得到相同结果，例如 `A<B` 与 `A_B` 都会变成 `A_B.dxf`。程序会在 Excel 标红和创建输出目录前检查这些冲突，指出涉及的工作表并停止，不自动改名或只保留最后一张。

请明确区分工作表名后再生成。检查按 Windows 不区分大小写的规则执行；正常不冲突的名字保持原输出规则。

## 保护输入图框

如果预计发布的 CAD 文件会覆盖本次输入的图框 DWG/DXF，会提前拒绝。仅选 DWG 时仍会保留兼容 DXF，因此这份 DXF 也会检查；只选 PDF、不发布 CAD 时不会仅因图框与输出在同一目录而拒绝。

建议为每次成果选择独立输出目录。生成流程仍可能按既定功能保存 Excel 的提出日期标红，验证时请继续使用原始文件的临时副本；这些检查不是全部操作的撤销机制。

## 标题栏定位必须唯一

同一个字段的主标记及所有别名会一起检查。例如 `作成日` 与 `20xx/xx/xx` 同时出现时，程序停止，避免选错位置。等价写法命中同一文字对象只算一个。

旧框的固定栏目标题与定位标记重名时，请按 [图框字段规范](图框字段规范.md) 添加冒号区分静态标题，或明确收紧模板的别名配置。原框不会被自动修改。
