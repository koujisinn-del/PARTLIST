# 材质符号按文字字号缩放：2026-10-26

## 完成内容

导入窗口默认使用“按文字字号匹配断面”。基准为普通 CAD TEXT 的名义字高，不是 N、T、B 等不同字母的轮廓范围。选定文字归一为字高 1，出图时整个符号再乘断面实际字号，因此所选文字和断面使用相同字号。外框、线条、其他文字保持原相对比例。

不要求外框是圆，方框、菱形、五角形、六角形和普通不规则二维图形使用同一方法。单个文字或多个同字高文字可自动选择基准；多个不同字高必须明确选择。无 TEXT 或字母已炸成线时不识别字形，明确提示改用整体高度或基准圆。旧的高度/圆径模式保留，旧规则不自动改变。

预览把符号和断面示例放在一个场景内，共用绘图单位到像素的比例，并复用实际出图的文字基线与组合定位。`材质符号_文字字号对照.png` 是从真实 CAD 输出提取的同字号、同基线对照。外框相对字高过大导致超行高时仍报错，不为塞入单元格偷偷缩小文字；自动调整行高/续表不在本次范围。

出图和预览共用同一断面文字定位公式；内置框内字、前置字母和断面保持相同可编辑基线。内置外框随框内实际字形轮廓移动，字本身不为居中而偏离断面基线；前置字母仍在外框外。triangle 中 WWW 这类宽字需避让斜边时只移动外框并保留 0.05 字高单位内距，不压缩文字或外框比例。新“按文字字号”导入规则保存选定基准 TEXT 索引，要求基准字高归一为 1 且水平旋转为 0 度；输出时整体平移使该基线与断面一致，并保持图形内部相对位置。旧自定义导入记录没有基线锚点，不猜测或迁移，继续按原位置出图；旧 height/circle 导入模式也不承诺文字基线对齐。

## 当前方案：文字基线优先，外框随文字定位

用户进一步指出，单独把框内字移到旧外框中心会使它低于后面的断面。当前实现先固定内置前置字母、框内字与断面的同字号、同基线，再将外框移到框内字的可见轮廓中心；三角宽字只移动框以保留最小内距。整个文字与符号组合统一放入单元格，不单独下沉材料符号。

新 text-mode 规则保存可选 `baseline_text_index`，指向过滤后的 TEXT 序列。选定文字须为单位字高、水平基线，索引不可为布尔值、浮点值或越界值。出图及预览共享实际文字定位方法，新导入几何整体以所选字基线对齐，内部相对布局保持。没有锚点的旧导入规则不迁移、不猜测基准；旧规则块名兼容，基线锚点纳入新规则身份与持久化。
