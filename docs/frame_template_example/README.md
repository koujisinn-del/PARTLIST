# 自建图框示例

此目录中的文件是为项目文档自建的虚构图框，不源自用户或现场 DWG，也不含私人项目资料：

- `frame_template_example_150x.dwg`：推荐作为 CAD 现场整理参考的 150 倍模型空间图框。
- `frame_template_example_150x.dxf`：同一示例的 DXF 源文件，便于检查几何和字段。

源外框为闭合 LWPOLYLINE，模型空间尺寸 63000 × 44550；包括内框、下方标题区和右侧日期履历字段。示例没有绘制固定部材表格，实际部材表仍由生成器根据 Excel 工作表动态排版。所有标记都是 modelspace 普通单行可编辑 TEXT。

请按 [图框字段规范](../图框字段规范.md) 为每个现场人工整理其自己的原始模板。每次生成从原始模板读取字段，替换动作只作用于输出副本；不要把生成结果回存为下一次输入模板。

150 倍仅指这个示例源图框的模型空间尺寸与 A3 纸面毫米的关系。当前生成器会把外框归一到 A3（420 × 297），输出 CAD 的 100/150/200 比例功能尚未实现。

重新生成这两个示例文件（需本机已有 LibreDWG，不下载组件）：

```powershell
.\.venv\Scripts\python.exe -B tools\generate_frame_template_example.py
```
