# 同页自动续表

部材表在保持整表字号、行高和文字内容的前提下，如果一个种类的数据超过单列高度，程序会从左向右创建同类续表。每列重复种类标题和完整表头，第二列起的标题附加 `(2)`、`(3)` 等序号。

- 优先整组换列。同一部件的多行断面能放进一整列时，尽量保持在同一列；上一列可能因此留白。
- 单个部件自身超过一整列时，才按原有行顺序分成连续片段；每个片段保留并重复原部件名称，包括大小写。
- 不改变原始断面字符，不漏行、不重复行，不单独缩小文字。材质符号继续与断面同字高、同基线。
- 续表模式按该种类全部内容测量最小列宽，并保留原有文字留白；同一类别的续列使用相同列宽。普通单表能放下时，沿用原有列宽分配。
- 按每列实际位置避开注记区；与注记区横向相交的列会提前结束。
- 如果所有续列仍无法放在当前动态表格范围，或注记区使该列连一行数据都放不下，会明确报错；生成入口在 Excel 标红和写出成果前检查布局。

同一张 A3 内向右续列，默认保持字号。动态范围沿用现场模板，操作时无需为每种部材手工指定表格起点、终点。后续已加入 [可选的整表字号降档](整表字号降档说明.md) 和 [100 / 150 / 200 CAD 输出倍率](CAD输出倍率说明.md)，更新追溯尚未启动。

验证使用虚构数据，不代表工程设计。自动回读和本机 PDF 检查仍不能代替 AutoCAD LT 2024 实际打开验收。
