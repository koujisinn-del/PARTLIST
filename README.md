# 部材表图纸生成器（开发中）

这是一个把 Excel 部材表转换为 A3 横向 PDF、DXF、DWG 图纸的桌面软件。正式发布前不设置软件版本号，当前标记为 `development`。

2026-09-11 材质功能已集成到同一个主界面：双击 `启动部材表生成器.cmd`，在“图纸设置”中勾选“按材质库生成符号”，通过“材质符号库”按钮查看基础及自定义规则。开关随现场模板和首选状态保存。详见 [材质库使用说明](material_libraries/使用说明.md)。旧 Excel 若将材质记号混在断面中，需要先把明确材质填入材质列后启用。部位列在现场 CAD 中的视觉居中仍待验证。

## 目前已经具备

- 读取 `.xlsx` / `.xlsm`；每个可见的部材 Sheet 生成一张图纸，文件名取 Sheet 名称。
- 按 Excel“种类”动态创建表格，不再只允许大梁、小梁；生成前弹窗列出每张图纸的种类和表格数量。
- 同名部件允许 1～N 行断面记录；图纸中名称格合并，断面等字段保持多行。
- 支持 `梁サイズ` 这类合并表头，并把其下连续列识别为部位和断面。
- 现场模板保存整体可用区域、表间距和表格样式；各类表格的位置与宽度在生成时自动计算。
- 在界面顶部通过名称管理现场模板：下拉选择后点击“读取”才应用，输入名称后点击“保存”可保存当前设置，同名时确认后覆盖更新。
- 未选中模板时自动显示排序最靠前的模板；再次打开软件时恢复最后一次真正读取或保存的模板。
- 现场模板保存输出文件夹、图框路径、排序和输出格式等界面首选项；DWG 文件本身不会写进模板。
- Excel “图纸列表”管理图纸名称、图号、0～N 版提出日期和更新履历。
- 本次提出日期单元格配置后，软件会把符合条件的图纸名称、图号、最新日期三个单元格标红，并直接保存回原 Excel。
- 软件内只读预览 Excel，并沿用源文件的合并格、对齐、字体、字号、换行和行高；运行过程写入本地日志文件。
- 日文 DWG 图框按原始版本转换并保留实体，自动识别 A3 外框、统一左下原点和比例，同时修复转换器产生的异常句柄和无效材质引用。
- 每张部材表内的表名、列标题和正文使用相同字号，长文字通过加宽列容纳，不单独缩字。不同表格可采用不同字号和单位行高。中日文使用兼容字体，特殊圆框 B 暂保留文本 `(B)`。
- 外部 DWG 可通过文字标记定位元数据：`図面名称`、`図面番号`、`R-X`、`20xx/xx/xx` 和 `20XX/XX/XX` 分别替换为 Sheet 名、图纸番号、最新版本、作成日和履历起点。
- 已兼容原始 `図面テンプレート.dwg` 的 `M5FL 部材リスト` 和分开的 `R-`＋数字；图号直接替换“図面番号”，日期履历仅写日期、从下向上排列。外部图框缺少或存在重复定位文字时停止生成并提示，不再退回概念图框坐标。
- 表格以 7 mm 为优先单位行高，空间不足时按整表调整；列标题也是一个单位行高，合并名称格为单位行高的整数倍。
- CAD 文字按实际字体边界检查，长文字不会越出单元格；PDF 默认使用白底黑线的黑白打印效果。
- PDF 中的文字使用嵌入字体，可选择和复制，不再转成轮廓图形。图纸 list 放在第一页，所有楼层图纸合为一个 PDF，DWG 仍分别输出。图纸 list 保留内容、合并和对齐，版本日期统一显示为 `YY.MM.DD`。
- DWG 采用日文代码页及 Unicode 转义，保留可编辑文字；保留原图框字体、大字体和字体族资料。新增文字使用 `Microsoft YaHei` 字体族，不将本机 PDF 使用的 TTC 文件名覆盖到图框样式中。
- 输出前检查转换日志，并回读核对文字的实际位置、对齐方式、字号、宽度、字体定义、可见性、实体数量和对象有效性。DWG 新增文字使用预先计算的基线位置，视觉居中、保留可编辑 TEXT；不把基线全部放在原点等待 CAD 重算。另检查原始 DWG 的字体扩展资料是否引用正确应用对象，避免 DXF 回读掩盖错误。检查失败不会覆盖已有 DWG。
- PDF 在独立副本中应用本机可嵌入字体，不修改 CAD 样式。DWG 字体仍依赖打开电脑上相应的字体；本机回读预览不等于 AutoCAD LT 的实际显示验收。
- 中文和日文界面；公司电脑当前采用 Python 源代码运行。

## 坐标与现场模板

所有 CAD 坐标以 A3 左下角为 `(0, 0)`，单位为毫米。程序内部的现场模板同时保存界面首选项和动态表格配置：

- `dynamic_table_layout.left/right/top/bottom`：全部动态表格可以使用的总区域；
- `dynamic_table_layout.horizontal_gap`：自动创建的表格之间的横向间距；
- `columns[].width`：自动分配剩余列宽时使用的比例权重；先保证每列能容纳统一字号下的最长文字，再按比例分配留出的空间；
- `dynamic_table_layout.text_height`：表格优先文字高度，默认 1.2 mm；密集表格按整表单位行高限制，不单格调整；
- `row_height` / `min_row_height`：优先行高和允许压缩到的最小行高；
- `tables[]`：不同种类可复用的样式预设；未配置的种类使用第一套样式。

因此，图框 DWG 与注记 DWG 只要都采用同一个 A3 左下原点，就能按原坐标叠加，不需要人工拖动。正式现场坐标取得后，只需修改模板，不需要改程序。

## 公司电脑运行

完整下载或克隆仓库后，不要只复制单个 Python 文件。中文版双击 `启动部材表生成器.cmd`，日文版双击 `起動.cmd`。首次启动若不存在项目环境，启动脚本会自动调用环境安装程序，完成后直接打开软件；以后更新源码不需要重复安装。

首次启动的前提是公司电脑已有获批的 Python 3.12 64 位（含 tkinter），并能通过公司配置的软件源安装 `requirements.txt` 中的依赖。依赖只安装到仓库内的 `.venv`，不要求管理员权限、不修改系统 Python。也可以分别双击 `安装开发环境.cmd` 或 `環境セットアップ.cmd` 手动准备环境。

仓库保留一个 `libredwg-0.14.8594-win64` 运行目录，用于直接读取和输出 DWG；不要从下载内容中单独删除它。Excel 预览只读取数据，不执行图纸生成校验，也不会在预览时改写 Excel。不制作生成器 EXE，公司电脑继续运行 Python 源代码。

项目过程和后续待办见 `项目开发记录.md`。

## 2026-09-04 修复后的文件与验证

开发机优先使用项目内 `libredwg-0.14.8594-win64` 转换组件，旧组件目录保留。公司源码 ZIP 排除这些 EXE/DLL；未另行批准组件时，使用附带的 DXF 图框生成 PDF/DXF，并在已有 CAD 中将 DXF 另存为 DWG。直接读取或输出 DWG 仅在公司批准转换组件后启用；没有组件时首次启动默认不勾选 DWG，误选会在读取/改写 Excel 前明确提示。

默认汇总 PDF 命名为 `Excel文件名_图纸.pdf`。旧输出目录里以前生成的单张 PDF 不会自动删除，新任务只生成一个汇总 PDF。DWG 同时保留 DXF 作为可恢复的交换文件。

如果按统一字号扩列后超过 A3 可用宽度，软件会明确提示需要调整整表字号或间距，不会自行单格缩字或分页。本机的回读对账不等同于所有 CAD 版本的打开验收，现场使用前仍应在目标 CAD 中打开核对。
